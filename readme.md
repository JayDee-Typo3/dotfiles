# dotfiles

Personal macOS setup (Apple Silicon): shell, terminal, tmux, Neovim and window
management. The repo lives in `~/Development/Repositories/dotfiles`; everything is used
via **symlinks** into the home directory, so editing a file here changes the live config.

| Path in repo | Linked to | What it is |
|--------------|-----------|------------|
| [`ohmyzsh/.zshrc`](ohmyzsh/.zshrc) | `~/.zshrc` | zsh with Oh My Zsh + Powerlevel10k |
| [`.p10k.zsh`](.p10k.zsh) | `~/.p10k.zsh` | Powerlevel10k prompt config |
| [`bash/.alias_list`](bash/.alias_list) | `~/.alias_list` | Aliases and shell functions |
| [`bash/setup-new-mac.sh`](bash/setup-new-mac.sh) | – | Bootstrap script for a new Mac |
| [`config/wezterm/`](config/wezterm) | `~/.config/wezterm` | WezTerm terminal |
| [`config/tmux/`](config/tmux) | `~/.config/tmux` | tmux, see [its README](config/tmux/README.md) |
| [`config/nvim/`](config/nvim) | entries of `~/.config/nvim/` | Neovim / LazyVim, see [its README](config/nvim/README.md) |
| [`config/aerospace/`](config/aerospace) | `~/.config/aerospace` | AeroSpace tiling window manager |
| [`config/amethyst/`](config/amethyst) | – | Amethyst window manager (legacy, replaced by AeroSpace) |

Common look across all tools: **Catppuccin Mocha** and **JetBrainsMono Nerd Font**.

## New Mac setup

```sh
bash <(curl -fsSL https://raw.githubusercontent.com/JayDee-Typo3/dotfiles/main/bash/setup-new-mac.sh)
# or, with the repo already cloned:
bash ~/Development/Repositories/dotfiles/bash/setup-new-mac.sh
```

`bash/setup-new-mac.sh` does, in this order:

1. Installs **Oh My Zsh** (keeps an existing `.zshrc`) and the **Powerlevel10k** theme.
2. Installs **Homebrew** (if missing), then `brew update`, `upgrade`, `doctor`
   (warnings from `doctor` don't abort the script).
3. Installs **DDEV** (`ddev/ddev` tap) and **mkcert** (+ `nss`) and sets up the local CA
   (`mkcert -install`).
4. CLI tools: git, composer, cmake, fd, ffind, fzf, gd, neovim, awk, tmux, lazygit, mas.
5. Clones the **LazyVim starter** to `~/.config/nvim` (old config backed up). Skipped if
   `~/.config/nvim/init.lua` is already a symlink, i.e. on a re-run.
6. GUI apps via cask: WezTerm, Arc, Chrome, Firefox, Brave, Postman, VS Code,
   JetBrainsMono Nerd Font, Docker Desktop, Ice, Raycast, 1Password, ChatGPT, Telegram,
   WhatsApp, Spotify.
7. Generates an SSH key `~/.ssh/id_rsa` (RSA 4096, **no passphrase**) unless one exists
   and prints the public key.
8. Creates `~/Development/Repositories` and clones this repo into it (skipped if it
   is already there).
9. Symlinks every folder in `config/` (except `nvim`) to `~/.config/<name>`. Existing
   targets are skipped, not overwritten.
10. Symlinks `.p10k.zsh` to `~/.p10k.zsh` (skipped if it exists).
11. Symlinks each entry of `config/nvim/` into `~/.config/nvim/`, then installs the
    plugins headless (`Lazy! sync`).
12. Symlinks `ohmyzsh/.zshrc` to `~/.zshrc` and `bash/.alias_list` to `~/.alias_list`.

Steps 11 and 12 skip links that already point to the repo; anything else in the way is
moved to `<name>.bak.<timestamp>`. The script can be run again safely.

WezTerm only reads `~/.config/wezterm/wezterm.lua` if there is **no** `~/.wezterm.lua`;
that file takes precedence, so don't keep a copy there.

## Shell (zsh)

[`ohmyzsh/.zshrc`](ohmyzsh/.zshrc):

- Oh My Zsh with the `git` plugin, theme `powerlevel10k/powerlevel10k`, instant prompt
  (quiet).
- Loads `~/.p10k.zsh`, then `~/.alias_list` and, if present, **`~/.alias_list_local`**,
  for machine-specific or private aliases that don't belong in the repo.
- `keychain` loads `id_rsa` into the ssh-agent (only if keychain is installed).
- `zoxide` (smarter `cd`, only if installed), Docker CLI completions.
- PATH additions: gittoolbox, Homebrew OpenJDK, `~/.local/bin`.

Prompt: [`.p10k.zsh`](.p10k.zsh), generated by the Powerlevel10k wizard (classic style,
Nerd Font v3, dark). Re-run with `p10k configure`.

### Aliases and functions ([`bash/.alias_list`](bash/.alias_list))

| Alias | Command |
|-------|---------|
| `n` | `nvim` |
| `lg` | `lazygit` |
| `t` | `tmux` |
| `gst` | `git status` |
| `gc` / `gcm` | `git commit` / `git commit -m` |
| `gp` | `git push` |
| `gw` | `git switch` |
| `cloud` | SSH to the home server |
| `dtf` | `ddev typo3 cache:flush` |
| `ddevUnitTest` | Run PHPUnit inside DDEV against the `func` test database |

| Function | What it does |
|----------|--------------|
| `gsm` | Switch to the remote's default branch (`origin/HEAD`) |
| `gmm` | `git merge --no-ff` the remote's default branch |
| `cflush` | Flush the TYPO3 cache in the current DDEV project; detects `typo3` (v12+) or `typo3cms` |

## Terminal (WezTerm)

[`config/wezterm/wezterm.lua`](config/wezterm/wezterm.lua):

- JetBrainsMono Nerd Font Mono, 14 pt, line height 1.2, **ligatures off**.
- Catppuccin Mocha, 80 % background opacity.
- Tab bar at the bottom, hidden when only one tab is open.
- No close confirmation for shells and tmux.
- Window maximised on start.

| Keys | Action |
|------|--------|
| `Cmd + ,` | Open the WezTerm config in Neovim in a new tab |
| `Cmd + Shift + R` | Rename the current tab |
| `Cmd + Shift + T` | Tab navigator |

## Window management (AeroSpace)

[`config/aerospace/aerospace.toml`](config/aerospace/aerospace.toml), starts at login,
tiling layout without gaps, mouse follows focus across monitors.

### Keybindings (main mode)

| Keys | Action |
|------|--------|
| `Alt + h/j/k/l` | Focus window left / down / up / right |
| `Alt + Shift + h/j/k/l` | Move window |
| `Alt + Shift + -` / `=` | Shrink / grow window |
| `Alt + /` | Tiles layout (toggle horizontal / vertical) |
| `Alt + ,` | Accordion layout (toggle horizontal / vertical) |
| `Alt + 1/2/3` | Go to workspace 1 / 2 / 3 |
| `Alt + Shift + 1/2/3` | Move window to workspace 1 / 2 / 3 |
| `Alt + Tab` | Previous workspace |
| `Alt + Shift + Tab` | Move workspace to next monitor |
| `Alt + Shift + ;` | Enter **service** mode |

### Service mode

| Keys | Action |
|------|--------|
| `Esc` | Reload config, back to main mode |
| `r` | Reset layout (flatten workspace tree) |
| `f` | Toggle floating / tiling |
| `Backspace` | Close all windows except the current one |
| `Alt + Shift + h/j/k/l` | Join with the neighbouring window |

### Workspaces and monitors

| Workspace | Monitor | Apps pinned to it |
|-----------|---------|-------------------|
| 1 | Built-in display | Outlook, Teams, WezTerm |
| 2 | ROG XG27AQ (home) / LG HDR 4K (work) | PhpStorm |
| 3 | XB271HU (home) / LG HDR 4K (work) | Arc, Chrome |

Every connected monitor must be covered by a workspace, otherwise AeroSpace parks a
phantom workspace on it.

Always **floating**: Finder, App Store, Calculator, Calendar, Chess, Clock, Dictionary,
FaceTime, Contacts, Books, Automator, Font Book, Home, Steam, Telegram, Docker,
1Password, Alfred workflows, Maccy, Raspberry Pi Imager, ChatGPT, Cyberduck, Sequel Ace.

### Amethyst (legacy)

[`config/amethyst/amethyst.yml`](config/amethyst/amethyst.yml) is the old window manager
config (tall + fullscreen layouts, modifiers `Option + Control` / `Cmd + Control + Shift`).
It isn't installed or linked anymore and is only kept for reference.
